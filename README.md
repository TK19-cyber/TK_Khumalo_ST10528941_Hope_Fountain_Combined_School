## Project Overview

Hope Fountain Combined School is a school based in Hillbrow, Johannesburg. The school provides education to learners from the surrounding community. The school aims to provide learners with a supportive environment where they can learn, develop their skills and prepare for their future.

The school provides academic education as well as opportunities to participate in sports and other activities. The website provides learners, parents, guardians and members of the community with information about the school.

---

## Website Goals and Objectives

### Goals

The main goal of the website is to create a simple and informative website for Hope Fountain Combined School. The website makes important school information easier to find and access.

The website provides information about the school, academics, sports and activities. It also provides contact information and forms that visitors can use to send questions to the school.

Another goal is to create a website that is easy to navigate and works on computers and mobile devices.

### Objectives

The main objective is to create six working web pages for the school website:

1. Home
2. About Us
3. Academics
4. Sports
5. Enquiry
6. Contact

The website includes a navigation menu that allows visitors to move between all six pages. It also contains school information, contact details and location links.

The enquiry and contact forms allow visitors to submit their details and messages. HTML and JavaScript are used to validate the information entered into the forms. AJAX is used to submit form data without leaving the current page.

### Key Performance Indicators (KPIs)

The success of the website can be measured by the number of visitors, the number of enquiries received and whether visitors can successfully navigate between all six pages.

Other measures include checking whether the website works on different screen sizes and browsers, whether form validation works correctly and whether submitted messages are delivered successfully.

## Part 3: JavaScript, Forms and SEO

### Form Validation

HTML form validation attributes and JavaScript are used to check visitor input before submission.

The forms check required fields, valid email addresses, name lengths, phone number formats and message lengths. Error messages are displayed when input is invalid.

### Form Submission and AJAX

The enquiry and contact forms use AJAX to submit form data to FormSubmit. This allows visitors to submit messages without leaving the current page.

The forms display messages to inform visitors whether their submission was successful or whether they should try again.

The receiving email address is configured as wandiletroy24@gmail.com.

### JavaScript Features

JavaScript is also used for interactive website features, including the school information toggle and subject search functionality.

### Search Engine Optimisation (SEO)

SEO improvements include page titles, meta descriptions, keywords, language attributes and viewport settings.

Navigation links and image alternative text are used to help improve accessibility and make the website easier to understand.

The project also includes a `robots.txt` file and a `sitemap.xml` file to support search engine crawling. These files must use the correct published website address before deployment.
