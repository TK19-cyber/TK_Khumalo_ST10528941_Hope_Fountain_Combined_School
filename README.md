## Project Overview
Hope Fountain Combined School is a school based in Hillbrow, Johannesburg. The school provides education to learners from the surrounding community. The school aims to provide learners with a supportive environment where they can learn, develop their skills and prepare for their future. 

The school provides learners with academic education as well as opportunities to participate in sports and other activities. The proposed website will provide learners, parents, guardians and members of the community with information about the school.  

## Website Goals and Objectives
Goals 

The main goal of the website is to create a simple and informative website for Hope Fountain Combined School. The website will make important information about the school easier to find and access. 

The website will provide information about the school, academics, sports and activities. It will also provide contact information and an enquiry form that visitors can use to send questions to the school. 

Another goal is to create a website that is easy to navigate and works on both computers and mobile devices. 

 Objectives 

The main objective is to create six working web pages for the school website. These pages will be the Home, About Us, Academics, Sports, Enquiry and Contact pages. 

The website will have a navigation menu that allows visitors to move between all the pages. It will also contain relevant information about the school and its activities. 

The website will include an enquiry form where visitors can enter their name, email address, enquiry type and message. JavaScript will be used to check that the required information has been entered. 

The website will also provide school contact information and location details.

### KPI 
The success of the website can be measured by the number of people who visit the website and the number of enquiries submitted through the enquiry page. 

The website can also be measured by checking whether visitors can successfully move between all six pages. Another important measure will be whether the website works correctly on different screen sizes and browsers.
